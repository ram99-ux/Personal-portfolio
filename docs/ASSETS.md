# Asset provenance

- `public/images/project-*.svg` and `journey-*.svg`: original vector compositions generated by `scripts/generate-art.mjs`. Fictional concept names and interface illustrations, not screenshots of client sites. Regenerate with `node scripts/generate-art.mjs`.
- `public/images/portrait-v2.png`: original fictional illustrated character generated with the built-in image generation tool, then processed with the imagegen skill's chroma-key removal helper. The source was inspected before use. It is not Ram Kumar's actual likeness. Replace this file with your own licensed portrait when ready.
- Archivo Variable and Manrope Variable: locally bundled via the `@fontsource-variable` packages under their included SIL Open Font License. These are substitutes for the reference's proprietary typefaces.
- Icons: Lucide React, under its ISC license; the favicon and wordmark are original code.
- No image, font, client logo, original source code, or other asset was downloaded from the reference for inclusion in this project.

## Portrait prompt (built-in image generation)

“Use case: stylized-concept. Asset type: portfolio website placeholder hero portrait. Create a premium realistic 3D clay-render illustrated bust of a fictional friendly young male developer, short neatly sculpted dark hair, medium warm brown skin, wearing a plain matte black crew neck t-shirt. Clearly a stylized three-dimensional character, not a photograph or a real person's likeness. Frontal chest-up portrait with shoulders and upper torso, subtle smile, arms down, generous space around head, centered, head near upper 8% and chest filling lower image. Soft polished studio lighting, realistic black fabric but simplified sculpted face, refined editorial aesthetic. No accessories, no laptop, no letters, no logos, no watermark. Portrait 1024x1536. Background must be perfectly flat solid #00ff00 chroma key for removal, no shadows on background, no gradients or floor plane, no green in the subject, crisp opaque smooth edges.”

The first result needed a background correction. Final edit prompt: “Edit this exact portrait. Change ONLY the backdrop behind the person to one completely flat bright chroma green #00ff00. The entire area outside his silhouette must be bright pure green, including around hair and shoulders. Absolutely no black, brown, blurred, textured, shadowed or gradient background. Keep the person, face, black shirt, hair, pose and all dimensions unchanged. This is a green screen cutout preparation.”

Final asset: `public/images/portrait-v2.png`. Chroma key sampled from the background; soft matte, thresholds 12/220, despill enabled. Keep the generated source outside the deployed public folder.
